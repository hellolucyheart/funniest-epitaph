The funniest epitaph in a single line of at most 170 characters: Dave spent his whole life saying he'd sleep when he was dead — so death finally granted him the sleep, and he is furious about it.

## Run it

```sh
python3 main.py
```

It validates the line (one line, 1–170 characters) and writes it to `/output/entry.txt`.
